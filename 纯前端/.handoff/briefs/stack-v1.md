# 轻量化与可移植性选型 v1

选用 **Preact + 原生 SVG + Vite 静态构建**。拓扑、流量统计窗口和事件表可由同一个快照驱动，组件边界也方便使用固定数据单独验证。SVG 让端口、箭头、MEMS 内部接线保持可寻址，切换时可复用已有节点。本次选型依据是本地参考实现和官方文档，最终体积由集成任务实测。

| 候选 | 开发与分发 | 对本页的影响 |
|---|---|---|
| 原生 JS + SVG | 已有原型直接加载本地脚本，无框架运行时 | 可以满足 4 ToR 规模；三处视图的更新、行排序与元素复用需自行维护。|
| Preact + SVG | 支持直接在浏览器运行，也可预构建组件；官网给出的核心库量级约 3 kB | 拓扑和排名可共享同一轮属性更新；开发端增加构建步骤，展示端只需静态文件。|
| Vue + SVG | 可使用本地独立脚本，也可用构建工具编译单文件组件 | 模板和响应式列表适合本页；团队若已有 Vue 组件可复用，本目录从空项目起步。|

部署单位为可整体复制的 `dist/`。用相对资源路径，本地打包字体以外的必要依赖，字体优先使用系统字体。用户在任意本地静态 HTTP 目录即可演示，全程无外网运行依赖。开发依赖与版本由集成窗口统一锁定。最终报告给出构建命令、产物大小、移动目录后实际访问方式。

资料：[Preact 官方介绍](https://preactjs.com/) · [Vue 官方入门与部署形式](https://vuejs.org/guide/quick-start.html) · [Vite 静态部署](https://vite.dev/guide/static-deploy.html)。
