# 光电网络总屏 · 项目上下文

交付对象是实验室演示者。打开页面即可看清端口怎么接、此秒哪些方向在传输、最近一次换路改变了什么。所有设备、速率和切换事件均在浏览器本地模拟。本轮范围仅含纯前端。

- 4 ToR 名称沿用 ToR0～ToR3；每台画 O、E1、E2、E3 四个对外端口。现有三组光路依据见上级目录《任务与资源总览.md》第 3 节。S01～S04 可作为机架标签，不计入四个对外端口。
- 既有「测试程序」的桌面截图和 HTML 已核对。可借鉴设备命名、端口映射和图例的可读性。新总屏以全网并发路径、速率榜与换路事件为主，独立设计和实现。
